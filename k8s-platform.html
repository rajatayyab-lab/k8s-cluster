Platform Stack

Every Tool, Its Purpose

Each component in the stack was chosen deliberately — below is what it does, and why it earns its place.

⎈
kubeadm
Cluster Bootstrap

Official Kubernetes bootstrapping tool that provisions a production-grade cluster on bare-metal in minutes. Manages certificates, configures control plane components, and handles node joining.

  • Certified, production-ready bootstrapper maintained by SIG Cluster Lifecycle
  • Reproducible cluster setup from config files — infrastructure as code
  • No cloud dependency, runs fully on local hardware
  • Supports HA control plane with multiple masters
🛡️
Cilium CNI
Container Network Interface

eBPF-powered networking layer that handles pod-to-pod communication, service mesh, and network policies without kube-proxy overhead. Hubble provides deep network observability.

  • eBPF bypasses iptables for significantly lower latency at scale
  • Built-in Kubernetes-aware network policies with L7 visibility
  • Hubble dashboard gives real-time flow observability with zero instrumentation
  • Replaces kube-proxy entirely for cleaner architecture
💾
Longhorn
Persistent Volume Claims

Cloud-native distributed block storage built for Kubernetes. Provisions PVCs backed by replicated volumes across all worker nodes — surviving node failure without data loss.

  • Data replicated across nodes — tolerates single node failure automatically
  • Native Kubernetes StorageClass, no external storage needed
  • Web UI for snapshot management, backup scheduling, and volume health
  • Lightweight — purpose-built for edge and bare-metal environments
🌐
MetalLB
Bare-Metal Load Balancer

Provides LoadBalancer type Services on bare-metal Kubernetes — assigns real IP addresses from a configured pool using L2 or BGP announcement. Bridges the gap between cloud and on-prem.

  • Enables real external IPs on-prem — no cloud load balancer required
  • L2 mode works out-of-the-box without BGP router setup
  • Seamlessly integrates with Traefik as the downstream ingress
  • Simple IP pool configuration via CRDs
🔀
Traefik
Ingress Controller

Modern HTTP reverse proxy and load balancer designed natively for containers and Kubernetes. Routes external traffic to the right services using IngressRoutes, with automatic TLS via Let's Encrypt.

  • Auto-discovers Kubernetes Services and Ingresses — zero manual reload
  • Built-in dashboard, metrics endpoint and middleware support
  • Automatic HTTPS with cert-manager or built-in ACME provider
  • Supports TCP/UDP routing and WebSockets natively
📊
Prometheus + Grafana
Monitoring & Alerting

The gold standard observability stack. Prometheus scrapes metrics from every workload, node and component. Grafana turns those metrics into rich dashboards and alert policies with full context.

  • Cluster-wide metrics: CPU, memory, pod lifecycle, network, storage
  • AlertManager integration for PagerDuty, Slack, email notifications
  • PromQL gives powerful time-series querying across all dimensions
  • Pre-built kube-prometheus-stack covers everything out of the box
⎈
ArgoCD
GitOps Continuous Delivery

Declarative GitOps controller that continuously reconciles cluster state with the desired state defined in Git. When manifests change, ArgoCD syncs automatically — the cluster always matches the repo.

  • Git is the single source of truth — full audit trail of every change
  • Drift detection alerts when cluster state diverges from Git
  • Rollback is a git revert — no custom tooling needed
  • Rich web UI and CLI for sync status, diff views, and health
⚙️
Jenkins
CI Automation Engine

Battle-tested open-source automation server that orchestrates the entire CI pipeline — triggered by Bitbucket webhooks, it runs quality gates, builds images, pushes to registries, and creates manifest PRs.

  • Massive plugin ecosystem connects to Bitbucket, SonarQube, Docker, ECR
  • Jenkinsfile in repo means pipeline is versioned alongside code
  • Parallel stages reduce total pipeline time significantly
  • Self-hosted — no CI minutes cost, full control over secrets and agents
🔍
SonarQube
Code Quality & Security

Continuous inspection platform that analyzes source code for bugs, vulnerabilities, code smells, and coverage regressions. Quality Gates block merges and builds when thresholds are not met.

  • Blocks broken or insecure code before it ever reaches an image build
  • Tracks code quality trends over time with per-project history
  • Supports 30+ languages including Java, Python, Go, TypeScript
  • Self-hosted Community Edition is fully free and sufficient for most teams
📦
ECR / Docker Hub
Container Image Registry

Secure, versioned storage for container images tagged by commit SHA. ECR integrates natively with AWS IAM for pull auth; Docker Hub is the universal default with broad toolchain support.

  • Immutable image tags per commit ensure exact reproducibility
  • ECR image scanning detects CVEs in layers automatically
  • Rollback is trivial — re-deploy the previous SHA tag
  • Both integrate with Kubernetes image pull secrets natively
🪣
Bitbucket
Source Control & PR Workflow

Atlassian's Git platform hosting both the application source and the eks-manifest deployment repo. Webhooks fire Jenkins pipelines; PRs gate manifest merges with code review.

  • Branch protection enforces PR approval before manifest merges
  • Webhook integration triggers Jenkins immediately on push
  • Jira integration links commits to tickets automatically
  • Both repos separated by concern: source vs deployment state
👁️
Hubble
Network Observability (Cilium)

Built on top of Cilium, Hubble provides a real-time service dependency map and flow viewer for all network traffic inside the cluster — no sidecars, no instrumentation required.

  • Service map shows live L4/L7 traffic between every pod and service
  • Flow filtering by namespace, pod, IP, port, or DNS name
  • Drops and policy verdicts visible in real-time dashboard
  • Zero overhead — reads directly from eBPF kernel events
